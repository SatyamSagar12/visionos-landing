Why it holds up

Why “I never approved that” stops working.

01The log refuses to be edited

Every action is written append-only and hash-chained. The database rejects updates and deletes, and one button checks the whole chain.

02A signature captures the document

Signing records the name, the moment, the IP address and a hash of that exact version. Change a word and it no longer matches.

03Approvals supersede, never overwrite

A re-agreed decision points back at the one it replaces and both stay, so the full sequence is there with a name and a price on each step.
